# 皇室战争 全部表情图鉴

一个**离线可用的单文件网页图鉴**，收录《皇室战争》游戏内 **591 条表情**。
所有图像、动画与音效均已渲染打包为本地资源，不依赖任何在线图床或接口 —— 双击 `index.html` 即可浏览。

## 特性

| 数量 | 说明 |
| --- | --- |
| **591** | 表情条目，全部含图（170px 高） |
| **542** | 可播放的原始动画，鼠标悬停时静图自动切换为动图 |
| **590** | 原版音效文件（591 条引用，其中 1 个被 2 条共用） |
| **101** | 家族分组，支持按家族筛选（同卡异名与进化形态已合并，如进化皇猪并入皇家野猪） |

交互功能：

- **搜索** —— 名称 / 家族 / 资源文件名三字段模糊匹配
- **筛选** —— 家族下拉、年份快捷条（2016–2026，共 10 个年份）、`★ 限定`（183 条）、`默认拥有`
- **排序** —— 游戏内序号 / 日期新→旧 / 日期旧→新 / 名称 A→Z / 家族分组
- **详情灯箱** —— `←` `→` 翻页、`S` 重播音效、`Esc` 关闭
- **音效** —— 点卡片自动播放一次；卡片右下角 `🔊` 单独试听；工具栏 `♫` 全局开关（状态存 localStorage）

## 快速开始

无需安装、无需联网，直接双击打开：

```
index.html
```

若想通过本地服务器打开（部分浏览器对本地音频策略更宽松）：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```

## 目录结构

```
.
├── index.html              # 自包含单文件页面（218 KB，数据内联）
└── assets/
    ├── emotes/             # 591 张 PNG 静图（170px 高，23 MB）
    ├── anim/               # 542 个 WebP 动图（128px / 20 帧，43 MB）
    └── sfx/                # 590 个 OGG 音效（游戏原版，19 MB）
```
